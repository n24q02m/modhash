# Contributing

## The three invariants

1. **Zero dependencies.** Every crate resolves with an empty
   `[dependencies]` table for non-workspace crates.
   `scripts/gate_zero_dep.sh` fails CI otherwise.
2. **Strict ordering.** A crate may only depend on a lower-numbered
   crate (§3 table). `scripts/gate_dag.py` checks edges AND
   completeness.
3. **No panics on hostile input.** Every malformed byte sequence is a
   named `Err`, not a panic. `cargo run -p modhash --bin fuzz` mutates
   inputs; CI runs 10 000 iterations.

## Style

- `#![forbid(unsafe_code)]` `#![deny(missing_docs)]` on every crate.
- Deterministic: SplitMix64 seeds, never a clock (bench aside — it
  measures wall time by design).
- `cargo fmt`, `cargo clippy --workspace --all-targets -- -D warnings`
  clean on stable AND 1.85.0.
- Fixtures are generated by scripts in `lab/` and committed with a
  `PROVENANCE.md`; corpora are never vendored (see `lab/README.md`).
- No number in docs without a receipt: run the command, paste the
  output into `docs/RECEIPTS.md` with the commit hash.
