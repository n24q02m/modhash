# Fuzz corpus provenance

Seeds for the corpus-backed fuzz targets registered by the kit facade phase (`modhash/src/bin/fuzz.rs`).

- `png/*`, `audio/*` are generated by `lab/phash_oracle.py` (same run that writes `modhash/tests/fixtures/`); `audio/` holds WAV (minimal PCM16 RIFF) and FLAC (hand-built verbatim frames) of the same synthesized tone.
- `jpeg/*` and `bmp/*` are byte copies of the conformance fixtures in `modhash-jpeg/tests/fixtures/` and `modhash-bmp/tests/fixtures/`; their provenance files there apply (Pillow 12.3.0 / hand-rolled byte writers).
- `mp4/minimal.mp4` predates this phase (see git history).

sha256 truncated to 16 hex digits.
