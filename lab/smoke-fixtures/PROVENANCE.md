# Fixture provenance - lab/smoke-fixtures

Byte copies of committed upstream fixtures plus two files generated by
the smoke lane. These are *fixtures* (small inputs the smoke script
exercises end-to-end), not evaluation corpora — corpus rules live in
`lab/datasets/manifest.toml` and nothing here is measured for accuracy.

| file | source |
|---|---|
| `base_444.jpg` | `modhash/tests/fixtures/` (jpeg lane conformance) |
| `base_444.png` | `modhash/tests/fixtures/` (png re-encode of the same pixels) |
| `l3_short.mp3` | `modhash/tests/fixtures/` (mp3 lane, 44.1 kHz) |
| `phash_rgb8_48x40.png` | `modhash/tests/fixtures/` (generated by `lab/phash_oracle.py`) |
| `p24_top_down.bmp` | `modhash-bmp/tests/fixtures/` (generated by that crate's `gen_fixtures.py`) |
| `text_page.pdf` | `modhash/tests/fixtures/` (byte copy of pdf lane's `standard_default.pdf`) |
| `tone.flac`, `tone.wav` | `modhash/tests/fixtures/` (identical PCM in two containers) |
| `minimal.zip` | generated at smoke-script authoring: Python `struct`/`zlib`, one stored member |
| `blob.bin` | generated: 48 KiB of SplitMix64 bytes, seed `0xDEADBEEFCAFEF00D` |
| `prose.txt` | generated: fixed English sentence, repeated |

committed byte sequence, so a changed upstream fixture changes the smoke
surface exactly as it should.
