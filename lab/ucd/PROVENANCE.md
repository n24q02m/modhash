## Table cardinalities the generator enforces (spec §4.1)

- canonical decompositions: **13 233** = 2 061 explicit + 11 172 algorithmic Hangul
- nonzero combining classes: **922**
- precomposed characters: **12 113** = 941 pair composites + 11 172 Hangul
- `Full_Composition_Exclusion` (1 120) must equal
  `CompositionExclusions.txt` (81) ∪ singleton/non-starter decompositions (1 039)
- `NormalizationTest.txt`: **19 074** data lines, all of which the generator's
  own reference NFC must satisfy before the blob is written

## How to reproduce

```sh
# from the repo root, with the four UCD files present in lab/ucd/
python lab/gen_unicode_tables.py
```

The script refuses to emit a blob when the table sizes differ from the
spec-pinned numbers, when the exclusion sets disagree, or when its own NFC
fails any conformance line — a wrong UCD drop fails loudly, not silently.
