# `modhash-bmp`

BMP decoding for 24/32-bit uncompressed images and RLE8 compression.

`decode` accepts `BITMAPINFOHEADER` (40), `BITMAPV4HEADER` (108) and
`BITMAPV5HEADER` (124) DIB headers in `BM` files:

- 24-bit `BI_RGB`, stored `B G R` per pixel;
- 32-bit `BI_RGB` (`B G R x`, fourth byte is padding) and
  `BI_BITFIELDS`/`BI_ALPHABITFIELDS` (channels read through the declared
  masks — order, width and position all honored);
- 8-bit `BI_RLE8` through a `B G R reserved` palette: encoded runs,
  absolute mode, end-of-line, delta and end-of-bitmap.

Bottom-up (`biHeight > 0`) and top-down (`biHeight < 0`) row orders both
decode to the canonical `Image<Rgba, u8>` with a top-left origin.
Unwritten RLE8 pixels keep the palette index 0 color; everything outside
scope (core headers, 1/2/4/16-bit, RLE4, embedded JPEG/PNG, OS/2 types)
is a named `Error::Unsupported`, never a mis-decode.

Fixtures under `tests/fixtures/` are generated byte-by-byte by
`gen_fixtures.py`; see `PROVENANCE.md` for hashes.

## Workspace rules

- `#![forbid(unsafe_code)]` and `#![deny(missing_docs)]` are not optional.
- Dependencies: `modhash-primitives` (#0), `modhash-raster` (#4).
- Zero external dependencies is enforced by `scripts/gate_zero_dep.sh`;
  the crate ordering is enforced by `scripts/gate_dag.py`.
