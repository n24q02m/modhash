# `modhash-mp3`

MP3 decoding for layers I/II/III including the bit reservoir.

**Status: implemented.** Decodes MPEG-1 audio Layers I, II and III
(`no_std` + `alloc`) — side-info parsing, the Layer III bit reservoir,
Huffman requantization, intensity/mid-side stereo, IMDCT with all four
block windows and the shared polyphase synthesis filterbank — into
interleaved `i32` PCM. Normative tables are generated by
`lab/mp3/gen_mp3_tables.py` and cross-checked against minimp3 and
libmad; the conformance suite in `tests/mp3.rs` compares against
ffmpeg-encoded fixtures.

## Workspace rules

- `#![forbid(unsafe_code)]` and `#![deny(missing_docs)]` are not optional.
- Dependencies: `modhash-primitives` (#0).
- Zero external dependencies is enforced by `scripts/gate_zero_dep.sh`; the
  crate ordering is enforced by `scripts/gate_dag.py`.
