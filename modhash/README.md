# `modhash`

The kit facade: canonical hash, tier 1, tier 2, match and describe.

`modhash` is the top of the workspace DAG (#21). It implements nothing
itself — it wires the modality crates behind one surface, per
`docs/algorithms/kit.md`:

- `detect(bytes)` sniffs the container (`png`, `jpeg`, `bmp`, `wav`,
  `flac`, `mp3`, `mp4`, `pdf`, `zip`, `gif` magic) and names the
  `Format` + `Modality`; bare UTF-8 is `Text`, the rest is `Binary`.
- `content_hash(bytes)` is **tier 1** — SHA-256 over the *normalized
  content*: `R G B` `u8` raster for images (alpha dropped, `u16 → u8`
  by `>> 8`); `rate ∥ frame count ∥ mono i32 LE` for audio; canonical
  text (NFC + lowercase + one `\n`) for text; raw bytes for binary.
- `signature(bytes)` is **tier 2** — the modality fingerprint: a 64-bit
  image pHash (luma → 32×32 box average → DCT-II → low 8×8 → median of
  the 63 non-DC coefficients), the spectral-peak `AudioSignature`, the
  128-word MinHash for text, or the FastCDC chunk-digest set for binary.
- `match_(&a, &b)` scores same-modality signatures (Hamming, audio
  votes, or Jaccard); cross-modality is `Error::BadValue`, not a zero.
- `describe(bytes)` returns format + modality + both tiers + facts.

Formats whose crate exists but has not landed (`mp3` → audio, `mp4` →
video, `pdf` → text) answer `Error::Unsupported` naming the modality;
formats outside the workspace vocabulary (gif, zip, unknown) fall back
to `Binary` semantics.

Every error carries the modality name; nothing in the public surface
can panic on untrusted input — corrupt claims are `Error::Decode` with
the modality attached.

## Tests and fixtures

`tests/fixtures/` and `tests/phash_vectors.rs` are generated by
`lab/phash_oracle.py` — an independent Python pHash implementation whose
committed output the Rust pipeline must match exactly, plus a
jpeg-vs-png acceptance pair and same-PCM `tone.wav`/`tone.flac`. See
`tests/fixtures/PROVENANCE.md`.

## Fuzz

This crate owns the workspace fuzz harness (`src/bin/fuzz.rs`):

```
cargo run --release -p modhash --bin fuzz -- <target> <iters> <seed>
```

Targets: `coremode`, `mp4`, `flac`, `png`, `jpeg`, `bmp`, `audio`.
Corpus seeds live in `fuzz/corpus/<target>/` (`fuzz/corpus/PROVENANCE.md`).

## Workspace rules

- `#![forbid(unsafe_code)]` and `#![deny(missing_docs)]` are not optional.
- Dependencies: `modhash-primitives` (#0), `modhash-inflate` (#1), `modhash-unicode` (#2), `modhash-math` (#3), `modhash-raster` (#4), `modhash-png` (#5), `modhash-bmp` (#6), `modhash-jpeg` (#7), `modhash-text` (#8), `modhash-fastcdc` (#9), `modhash-wav` (#10), `modhash-flac` (#11), `modhash-mp3` (#12), `modhash-audio` (#13), `modhash-mp4` (#14), `modhash-h264` (#15), `modhash-video` (#16), `modhash-zip` (#17), `modhash-pdf` (#18), `modhash-tier3` (#19), `modhash-index` (#20).
- Zero external dependencies is enforced by `scripts/gate_zero_dep.sh`;
  the crate ordering is enforced by `scripts/gate_dag.py`.
